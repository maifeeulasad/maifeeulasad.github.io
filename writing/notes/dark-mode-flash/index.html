Preventing dark mode flash on static sites

MUA
Maifee Ul Asad
Nov 07, 2026·schedule 1 min read
XLinkedInFacebookmailEmail

The flash of incorrect theme happens because stylesheets apply before any script that reads localStorage has a chance to run. The fix is to read it synchronously, inline, in <head>:

<script>
  try {
    var t =
      localStorage.getItem('theme') ||
      (matchMedia('(prefers-color-scheme: dark)').matches ? 'dark' : 'light');
    document.documentElement.setAttribute('data-theme', t);
  } catch (e) {}
</script>

Put it before the stylesheet link, keep the whole payload tiny, and never move it into an external file.
